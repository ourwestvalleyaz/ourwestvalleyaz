---
title: "Privacy"
description: "How Our West Valley AZ protects resident privacy."
---

Our West Valley AZ is designed around a simple privacy principle: residents
should be able to access civic information without being tracked, profiled,
or required to identify themselves to OWVAZ.

_Last updated: September 8, 2026._

## What OWVAZ does not use

The OWVAZ website is designed without:

- resident accounts
- advertising networks
- behavioral analytics
- tracking pixels
- browser or device fingerprinting
- third-party social trackers
- third-party analytics scripts
- third-party advertising scripts
- persistent browser storage for tracking or profiling

OWVAZ does not sell resident information or use the website to build
advertising, behavioral, or personal profiles of visitors.

## Cookies and browser storage

The current OWVAZ site code does not set cookies and does not use
`localStorage`, `sessionStorage`, or IndexedDB to identify, track, or profile
residents.

If a future feature requires cookies or persistent browser storage, its
privacy impact must be evaluated before that feature is added and this page
must be updated when appropriate.

## Search privacy

OWVAZ search is designed to operate in the resident's browser.

When a resident searches OWVAZ, the site loads static OWVAZ search-index data
from the same website and performs the search locally in the browser. The
search form does not submit the resident's search terms to OWVAZ, a search
engine, an analytics provider, or another third-party search service.

Loading a search index is a normal request for a static website file. The
resident's typed search term is not included in that request.

## Forms and information residents submit

The current public site does not provide a contact form or other form that
submits personal information to OWVAZ. The forms currently present on the
site are search interfaces and do not have a network submission endpoint.

If OWVAZ later adds a way for residents to submit corrections, sources,
questions, or other information, the privacy implications and handling of
that information will be documented before or when that feature is made
available.

## External links

OWVAZ links to official government agencies, public meeting systems,
utilities, public documents, and other external sources.

Following one of those links takes the resident to a website that OWVAZ does
not operate or control. That external site may have its own cookies,
analytics, logging, privacy practices, or terms.

OWVAZ does not treat a link to an external website as permission for that
site to track residents through OWVAZ. External resources are linked rather
than automatically embedded whenever practical so residents can choose
whether to visit them.

## Website requests and infrastructure

Like any website, OWVAZ must receive a network request in order to send a
requested page or file to a visitor's browser. That request can inherently
include technical information needed for normal Internet communication,
such as an IP address and basic request information.

OWVAZ does not intend to use website infrastructure to track or profile
residents.

The production hosting, web-server, reverse-proxy, CDN, and related
infrastructure configuration will be evaluated separately for request
logging and data-retention behavior. OWVAZ will not claim that no
infrastructure-level logs exist unless that has been verified.

## Privacy by design

Privacy is treated as a design constraint rather than an optional feature.
New analytics, tracking, advertising, profiling, third-party embeds, or
similar technologies are not assumed to be acceptable merely because they
are common on other websites.

If OWVAZ considers adding a feature that changes how resident information is
handled, its purpose and privacy impact should be evaluated first.

## Changes to this privacy information

OWVAZ's privacy practices and this page should be reviewed when a material
change affects how resident or visitor information is handled.

If OWVAZ adds a feature, service, or production technology that materially
changes the privacy practices described here, this page should be updated to
reflect that change.
