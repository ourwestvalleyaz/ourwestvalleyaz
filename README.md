# Our West Valley AZ

Neighbors. Information. Community.

Our West Valley AZ is a resident-friendly civic information website for
Arizona's West Valley.

Core concept:

> Find it. Understand it. Go to the source if you want more.

Primary design principle:

> One glance for the answer. One click for the details.

## Repository responsibility

This repository contains the public source for the Our West Valley AZ website,
including Hugo content, structured civic data, layouts, frontend assets,
public data schemas, and search data.

Internal tooling, validation, tests, operational documentation, retained public
records, research artifacts, extraction output, temporary datasets, and
working data are maintained separately and are not part of this public
repository.
